# cursor-playground

**English** · [한국어](#korean)

A collection of mouse cursor experiments. A hobby playground.

## Contents

One folder per piece of work, each with its own short README.

- [win-cursor](win-cursor/) — draw Windows cursors as pixel art and install them as 120 pointer schemes (20 animated, all 17 slots filled) in four cursor shapes
  - [Preview page](https://ruminem.github.io/cursor-playground/win-cursor/preview.html) — try each scheme as your cursor in the browser, recolour it with a hue slider, draw your own, then after a one-line setup apply it to Windows, schedule one per time of day or roll back with a button
  - [cursors.bat](win-cursor/cursors.bat) — register, remove and check schemes from a clone (for when you edit the art)
- [cat-follower](cat-follower/) — a pixel cat that follows the cursor around the desktop, sits next to it and falls asleep. Double-click [cat.bat](cat-follower/cat.bat) to show or hide it

## Korean

[English](#cursor-playground) · **한국어**

마우스 커서 관련 실험 모음. 취미용 놀이터임.

### 구성

작업물 하나당 폴더 하나로 둠. 각 폴더에 짧은 README를 붙임.

- [win-cursor](win-cursor/) — 픽셀아트로 윈도우 커서를 그리고 포인터 구성표 120종(움직이는 커서 20종 포함, 17칸 전부)을 커서 모양 네 가지로 등록
  - [시안 페이지](https://ruminem.github.io/cursor-playground/win-cursor/preview.html) — 구성표를 골라 가며 커서를 만져 보고, 색조 슬라이더로 색을 바꾸고, 직접 그려 보고, 한 줄 설치 뒤 버튼으로 윈도우에 적용·시간대별 자동 전환·원래대로
  - [cursors.bat](win-cursor/cursors.bat) — 클론한 폴더에서 구성표 등록·제거·상태 확인 (그림을 고칠 때)
- [cat-follower](cat-follower/) — 바탕화면에서 커서를 따라다니다 옆에 앉고 잠드는 픽셀 고양이. [cat.bat](cat-follower/cat.bat) 더블클릭으로 켜고 끔
