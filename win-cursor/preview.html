win-cursor · 포인터 구성표 50종

cursor-playground schemes

텍스트 픽셀아트로 그린 윈도우 커서 구성표 50가지를 7갈래로 묶음. 구성표를 고르면 이 페이지의 커서가 먼저 바뀌고, 마음에 들면 버튼 하나로 윈도우에 바로 적용함. 이것저것 적용해 보다 질리면 원래대로 누르면 페이지를 열기 전 커서로 돌아감.

처음 한 번

윈도우 PowerShell 을 열고 아래 한 줄을 붙여넣음. 버튼을 받아 줄 작은 스크립트를 설치하고, 지금 마우스 포인터 설정을 백업해 둠(완전 제거 때 여기로 돌아감). 관리자 권한 필요 없음.

irm https://ruminem.github.io/cursor-playground/win-cursor/setup.ps1 | iex

인터넷의 스크립트를 받아 바로 실행하는 명령이라, 붙여넣기 전에 setup.ps1 과 handler.ps1 내용을 확인할 수 있음.

끌어서 옮기는 영역

페이지 기본 커서도 고른 구성표의 일반 선택. 브라우저가 커서 이미지를 막는 환경에서는 기본 커서로 대신 보임.

그 밖에

  • 원래대로 는 이 페이지를 연 뒤 처음 적용하기 직전 커서로 돌아감. 페이지를 닫았다 다시 열면 그때부터 새로 셈 (같은 탭 새로고침은 이어짐).
  • 포인터 설정 열기 는 윈도우 마우스 속성 창을 포인터 탭으로 엶. 칸 하나만 바꾸거나 구성표를 직접 고를 때.
  • 버튼을 눌렀는데 아무 반응이 없으면 이 PC에 설치가 안 된 것 — 위의 한 줄부터.
  • 그림을 직접 고치려면 저장소를 받아 art/ 를 고치고 python build.py. 로컬 메뉴는 win-cursor/cursors.bat.
  • 다 치우고 싶으면 — 한 줄 설치할 때의 커서로 돌린 뒤 버튼 연결과 설치 폴더까지 지움.

다음에 브라우저가 앱을 열지 물으면 열기를 누름.
